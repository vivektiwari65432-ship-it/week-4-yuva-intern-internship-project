# week-4-yuva-intern-internship-project
This project upgrades the Week 3 Interactive Web Experience with:
- semantic HTML landmarks
- skip-to-content navigation
- accessible button names and expanded/pressed states
- keyboard-visible focus styles
- live regions for dynamic messages
- improved form validation and error states
- reduced repeated DOM queries
- IntersectionObserver for the statistics animation
- responsive CSS for desktop, tablet and mobile
- `prefers-reduced-motion` support

## Files
- `index.html` — semantic and accessible page structure
- `style.css` — optimized, responsive styling
- `script.js` — optimized interactions and validation
- `report/week-4-report.docx` — technical report

## Testing
Run the page locally and test:
1. Chrome/Edge DevTools → Lighthouse → Performance + Accessibility.
2. Test keyboard-only navigation using Tab/Shift+Tab/Enter.
3. Test viewport widths: 1440px, 1024px, 768px, 390px.
4. Run WAVE or axe to check accessibility findings.

Do not invent Lighthouse scores; record the actual scores from the environment used for submission.
